# Pilot implementation checklist and scorecard

Commercial target: by 15 October 2026, publish one working release, test three
real workflows with permission, and secure one paid implementation. These are
separate targets, not forecasts or current achievements.

Before each pilot: obtain permission, identify the operator and organization,
confirm the statement format/currency, document external AI processing if used,
configure read-only scopes, agree retention and identify the reviewer.

Measure review accuracy before claiming time savings. Count operator correction
time and time spent investigating false findings. Record limitations and failed
runs. Keep customer evidence private; publish names or results only with permission.

Paid implementation checklist: agreed scope and price, verified input layout,
operator-owned accounts, installation, realistic acceptance run, training,
documented handover and any agreed support. Record a signed/paid outcome only
when it actually exists. Outreach remains draft-only unless separately authorized.
