# Supplier Statement Checker 0.1.0

Initial implementation of the read-only checker, deterministic TypeScript core,
n8n live and synthetic workflows, optional reviewed OpenAI PDF extraction, and
evidence-backed HTML/CSV/JSON reports. Includes synthetic CSV/PDF fixtures,
MIT license, setup documentation and bilingual Bjorvand AI page sources.

Verified locally: deterministic tests, reproducible generated workflows, native
n8n CSV/PDF/failure scenarios, synthetic OpenAI extraction, and browser download
of the report ZIP with byte-for-byte content checks.

This draft is **not a completed production release**. Live Xero OAuth and test
organization verification, n8n Cloud fresh-install verification, template
directory submission and site deployment remain separate gates. Three customer
pilots and a paid implementation have not occurred. YouTube is deferred.
