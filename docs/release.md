# Release and publication

1. From a clean checkout on Node.js 24, run `npm ci`, `npm run check` and `npm run demo`.
2. Import the synthetic workflow into fresh self-hosted and Cloud workspaces.
   Verify authenticated access, summary, ZIP download and all artifact contents.
3. Test the live workflow with the intended Xero test organization. Record tenant
   confirmation, scopes, refresh behavior, complete pagination, paid bills and
   working bill links. Do not seed or change accounting records through the checker.
4. Run live OpenAI extraction only with synthetic fixtures. Review exact field
   and source-reference accuracy; do not treat schema conformance as accuracy.
5. Check exported JSON for credentials, pinData, customer identifiers and private
   endpoints. Confirm the checksums and record the tested Git commit.
6. Publish source, license, lockfile, tests and synthetic fixtures. Tag the tested
   release and attach the live and demo workflow JSON, checksums and sample ZIP.
   Keep the previous release available. Do not describe a preview as fully verified.
7. Submit the inactive template through the n8n creator portal with the overview,
   requirements, setup steps, read-only scopes, limitations, privacy and costs.
   Record submission receipt/status. Submitted is not accepted.
8. Publish the bilingual workflow pages only when their release download exists.
   Verify downloads, metadata, language alternates, sample report and English and
   Norwegian booking paths on the deployed site. The other site's uncommitted
   work must be handled in its own release scope.

Preview distribution may link to the already-public workflow file at a verified,
immutable Git commit while the stable release is pending. Label the page and
each listing as a preview and keep the outstanding live-provider checks visible.
This does not satisfy the stable-release acceptance gates.

## Template directory description

Compare a supplier statement against Xero purchase bills with evidence-backed
exceptions. Upload CSV or a text PDF, choose one supplier and currency, confirm
extracted lines, then download HTML, CSV and JSON. References and original totals
are checked deterministically. Paid bills are included. Ambiguous candidates,
credits, partial payments and outstanding-only lines require review. Incomplete
API retrieval stops the check. Read-only Xero access; no accounting posting or
email delivery. Optional OpenAI PDF extraction uses operator credentials.

## Website integration

`site-integration/` contains the Norwegian source, CSS and reviewed English copy.
`node scripts/install-site-page.mjs PATH_TO_BJORVAND_AI` installs only this feature
and adds one sitemap entry to the current localization-aware sitemap structure.
Run the site's localization, typecheck, lint, production build and responsive QA.
The English source is generated by the site's own tooling, never edited directly.

YouTube production is explicitly deferred. Use the real synthetic example report
on both pages; do not show a placeholder video or claim a recording exists.
