# Security reporting

Report suspected vulnerabilities privately to
[kevin@bjorvand.ai](mailto:kevin@bjorvand.ai?subject=Xero%20Supplier%20Statement%20Checker%20security%20report).
Include the affected commit, a description of the impact and a synthetic
reproduction. Do not send credentials, access tokens, real supplier documents
or raw customer accounting data.

Avoid disclosing exploitable details in a public issue before the maintainer has
had an opportunity to investigate. No response-time commitment or paid security
support is implied.

The project is in preview; no production-supported release has been declared.
See the [verification record](docs/verification.md) for current release gates and
the [data-handling guide](docs/security.md) for scopes, storage and retention.
